# Licences

Montaj itself is licensed under Apache-2.0 (`LICENSE`). The four workspace packages (`montaj-core`, `montaj-api`, `montaj`, `montaj-mcp`, all 0.1.0) declare Apache-2.0.

This page lists the third-party runtime packages installed by `uv sync --all-packages` from `uv.lock`, with the licence each package declares in its metadata. It is a summary, not legal advice; check each project's own licence file before you redistribute.

## How this list was made

The list comes from walking the runtime requirements of `montaj-api`, `montaj-mcp`, `montaj-core` and `montaj` with `importlib.metadata` in the project's virtual environment (Windows, Python 3.12). For each package the licence is taken from `License-Expression`, else the `License` field, else the trove classifiers (marked "classifier"). Development tools (pytest, ruff, mypy) are not included. On Linux the set is the same minus `pywin32`.

## Points worth knowing

- **soxr** (LGPL-2.1-or-later) is a dependency of librosa. It is used as a dynamically loaded Python extension. If you ship Montaj in a product, meet the LGPL terms for it (allow replacing the library, provide its source on request).
- **certifi** (MPL-2.0) and **tqdm** (MPL-2.0 AND MIT) carry file-level copyleft: changes to their files must stay open.
- **OpenCV**: only **opencv-python-headless 4.14** is installed. Montaj requires the headless 4.x build (`opencv-python-headless>=4.10,<5`, because OpenCV 5 removed the Haar face cascades Montaj uses). scenedetect asks for the GUI wheel `opencv-python`, which installs into the same `cv2` module; the root `pyproject.toml` drops it with uv's `exclude-dependencies = ["opencv-python"]`, and a test fails if `opencv-python` is installed or face detection is unavailable. An environment synced before this change may still hold `opencv-python` 5; run `uv sync --all-packages --reinstall-package opencv-python-headless` once to repair it. The wheel is Apache-2.0 but bundles third-party native libraries under their own licences (FFmpeg among them).
- **pywin32** (PSF) is installed on Windows only, by the `mcp` package.
- Every installed package reported a licence; none was missing.

## FFmpeg

Montaj does not link to FFmpeg. It runs the `ffmpeg` and `ffprobe` executables as separate processes with argument lists. You install FFmpeg yourself (or the Docker image installs Debian's `ffmpeg` package).

FFmpeg is LGPL-2.1-or-later, or GPL-2.0-or-later when built with GPL components. Montaj encodes with `libx264` and optionally `libx265`, which are GPL, so typical builds that Montaj can use (including Debian's) are GPL builds. Running a separate executable does not change Montaj's own licence, but if you distribute an image or bundle that contains FFmpeg, you distribute FFmpeg under its licence and must meet its terms. The Docker image does this through the Debian package, whose licence and copyright files are in `/usr/share/doc/ffmpeg`.

## Fonts

Text overlays ask libass for Arial. The Docker image installs `fonts-dejavu-core` (DejaVu fonts: a free licence derived from the Bitstream Vera licence) as the fallback. No fonts are bundled in the repository.

## The Claude director

The `anthropic` SDK is Apache-2.0. Using the Claude director sends prompts and thumbnails of your media to the Anthropic API under your own Anthropic account and terms. Without an API key no data leaves the server for planning.

## Optional extras

Not installed by default. Their dependencies are not in the table below.

| Extra (montaj-core) | Packages | Use |

| `rembg` | `rembg[cpu]`: rembg (MIT) and onnxruntime (MIT), with their own dependencies | the `remove_background` image operation (model `birefnet-general`, fetched by rembg on first use; check the model's own licence) |

There are no other extras.

## Music

No music is bundled. The procedural bed is generated by Montaj's own code and its licence record says "Generated by Montaj's procedural synthesiser; no third-party rights". You are responsible for the rights to tracks you upload or register in the library. See [styles-and-music.md](styles-and-music.md#the-licence-record).
